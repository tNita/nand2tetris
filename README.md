# nand2tetris

This repository contains my implementations of the projects from [Nand2Tetris](https://www.nand2tetris.org/) (*The Elements of Computing Systems*).  

Each directory corresponds to a chapter/project from the course starting from basic logic gates and ending with a working compiler and standard library for the Jack language.

## Project Layout

- `01` – Boolean Logic (Elementary logic gates)
- `02` – Boolean Arithmetic (Adders, ALU, and core arithmetic components)
- `03` – Memory (Registers, counters, RAM hierarchy)
- `04` – Machine Language (Hack assembly programs)
- `05` – Computer Architecture (CPU, Memory, and the complete Hack Computer)
- `06` – Assembler (Assembler written in Python)
- `07_08` – Virtual Machine translator (VM → Hack assembly)
- `10_11` – Jack Compiler (Jack → VM)
- `12` – Jack standard library (Operation System)
