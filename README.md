# nand2tetris

This repository contains my implementations of the projects from [Nand2Tetris](https://www.nand2tetris.org/) (*The Elements of Computing Systems*).  

Each directory corresponds to a chapter/project from the course starting from basic logic gates and ending with a working compiler and standard library for the Jack language.

## Project Layout

- `01_boolean_logic` – Chapter 01: Boolean Logic (Elementary logic gates)
- `02_boolean_arithmetic` – Chapter 02: Boolean Arithmetic (Adders, ALU, and core arithmetic components)
- `03_memory` – Chapter 03: Memory (Registers, counters, RAM hierarchy)
- `04_machine_language` – Chapter 04: Machine Language (Hack assembly programs)
- `05_computer_architecture` – Chapter 05: Computer Architecture (CPU, Memory, and the complete Hack Computer)
- `06_assembler` – Chapter 06: Assembler (Hack assembly → Machine Language)
- `07_08_vm` – Chapters 07-08: Virtual Machine translator (VM → Hack assembly)
- `10_11_jack_compiler` – Chapters 10-11: Jack Compiler (Jack → VM)
- `12_jack_os` – Chapter 12: Jack standard library (Operating System)


Projects 06–08 (assembler and VM translator) and 10–11 (Jack compiler) are implemented in Python.
